# SkillTrack

A modern web application designed to help developers and technical professionals map competencies, track learning milestones, and manage continuous career growth.

## Problem

Technical professionals often struggle to manage skill acquisition across diverse, rapidly evolving domains. Learning progress is frequently scattered across disparate notes, bookmarks, and course platforms without a unified view of proficiency levels or clear milestones toward career goals.

## Solution

SkillTrack provides a centralized dashboard to:
- Map skills across categories, frameworks, and tools.
- Set measurable milestones and track progress over time.
- Gain clear insights into skill strengths and growth areas.

## Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler / Dev Server**: [Vite 6](https://vite.dev/)
- **Language**: JavaScript (ES Modules / JSX)
- **Styling**: Modern Responsive CSS

## Setup, Run, and Build Instructions

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher)

### Installation
Clone or navigate to the project directory and install dependencies:
```bash
npm install
```

### Development
Start the local development server with Hot Module Replacement (HMR):
```bash
npm run dev
```

### Production Build
Build optimized production assets:
```bash
npm run build
```

### Preview Build
Locally preview the production build:
```bash
npm run preview
```

### Testing
Run unit tests:
```bash
npm test
```
